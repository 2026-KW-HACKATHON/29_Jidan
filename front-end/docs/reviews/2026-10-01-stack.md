## 검증 한계와 후속 작업

- API 명세가 없으므로 실제 Google 로그인·프로필 저장·권한 종료 서버 연결은 수행하지 않습니다. 기본 서비스에 추정 HTTP 경로·쿠키·콜백 계약을 추가하지 않았습니다. UI 테스트는 주입 서비스로 검증합니다.
- Docker CLI 인자 검사는 mock 실행입니다. 실제 ARM64 이미지 빌드·서버 배포·배포 후 nginx 검증은 로컬에서 수행하지 않았습니다. GitHub CI 결과는 원격 실행에서 별도로 확인합니다.
- 기존 Linux 배포 테스트 19개 중 10개는 이 macOS 환경에 `flock`이 없어 실행 실패했습니다. 프론트엔드 테스트 통과를 전체 Linux 배포 검증 통과로 해석하지 않습니다.
- 모든 화면의 픽셀 단위 대조와 좁은 실제 브라우저 너비의 전체 검수는 완료로 표시하지 않습니다.
- #51의 Figma 문구 동기화는 도구의 `Pretendard GOV` 폰트 부재로 미반영 상태가 있습니다. 프론트엔드 문구는 반영했으며 다른 폰트로 원본을 교체하지 않았습니다.
- #53의 미리보기 제거는 실제 MVP 인증·진입 흐름 확인 및 릴리즈 시점에 수행합니다.
