# 일반회원 대타 지원

Figma: 작성 530:3183·530:3201, 완료 635:2273, 철회 635:2483.

- `ApplicationDialog`는 공고·지원 효과·성공/닫기 콜백을 주입받습니다. `ApplicationComplete`는 지원 결과·철회 효과·복귀 콜백을 주입받습니다.
- `ApplicationService`는 UI 효과 주입 지점이며 서버 계약이 아닙니다. 기본 서비스는 미설정 오류를 반환합니다. HTTP 경로·인증·실제 알림·경력 전달은 명세 확정 후 연결합니다.
- 자기소개는 빈 값과 공백/보이지 않는 문자만 있는 값을 거절합니다. `Intl.Segmenter`의 grapheme 기준으로 한글·이모지·결합 문자를 세며 최대 500자입니다. 붙여넣기는 500자로 제한하고 IME 입력은 조합 완료 후 제한합니다. 개행도 한 글자로 셉니다. 실제 전달하는 문자열의 앞뒤 공백은 제거합니다.
- 제출·철회는 중복 실행을 막고 10초 응답 대기 제한을 사용합니다. 실패 시 입력/지원 상태를 유지합니다. 닫기·화면 해제 시 요청을 취소하며 늦은 완료 결과로 화면을 이동하지 않습니다.
- 미리보기 샘플 지원은 공고 ID별로 한 건만 유지합니다. 철회 성공 시 샘플 지원과 지원자 수를 갱신하고 일반회원 공고 탐색으로 돌아갑니다. 새로운 샘플 예시·다른 페이지·새로고침에서는 초기화합니다. 실제 신청 목록·홈 통계의 영속 저장을 의미하지 않습니다.
- 검수 대시보드 `/__preview`의 대타 공고 항목에 작성 전·작성 완료·지원 완료·철회·각 실패/재시도 예시가 있습니다. `fail=1`은 제출과 철회의 첫 요청을 각각 실패시킵니다.
- 같은 공고에 이미 지원한 상태에서는 상세 버튼이 지원 확인으로 바뀌며, 뒤로 이동해서 중복 제출하지 않습니다.
- 운영 빌드는 검수 대시보드와 mock 데이터를 제외합니다. 이 구현은 API/DB E2E 검증이 아닙니다.
