# 근무자 초대 UI

Figma 220:1333, 248:1424, 506:4035/4082/4114/4633/4669 기준으로 생성·수락·거절·관리·취소·재전송을 제공합니다.

- API 경로·메일 발송·초대 토큰 계약은 정의하지 않습니다. InvitationService/InvitationManagementService를 주입하며 기본 서비스는 미연결 오류를 반환합니다.
- 초대 데이터의 status·expiresAt·accessUntil은 서버에서 제공할 값입니다. 클라이언트가 임의의 기준으로 만료 예정 또는 접근 기간을 판정하지 않습니다.
- 재전송은 기존 초대의 expiresAt을 변경하지 않습니다. 만료 초대는 새로운 초대를 생성하는 화면으로 이동합니다.
- 미리보기 `/__invitations`의 데이터와 서비스는 샘플입니다. 생성·취소·응답 결과는 같은 미리보기 안에서 유지되며 새로고침하면 초기화합니다. 날짜는 Figma의 고정 예시로 실제 유효 초대를 의미하지 않습니다.
- `/__invitations?view=create`, `?view=accept`, `?view=past`, `?empty=1`, `?overlay=cancel`, `?overlay=resent`로 각각 검수합니다. `&fail=1`은 첫 명령 실패 후 재시도 성공을 재현합니다.
- 모든 명령은 중복 실행 방지, 10초 클라이언트 대기 제한, 화면 해제 시 취소를 적용합니다. 이메일은 공백 제거 후 형식과 최대 254자를 검증합니다.
