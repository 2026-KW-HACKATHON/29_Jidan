- Figma: 탐색 468:2984, 필터 468:3196. 카드·필터·하단 메뉴는 공통 UI와 기존 SVG를 재사용합니다.
- API 명세가 없으므로 HTTP 경로를 추가하지 않습니다. 공고와 기준 날짜, 화면 이동을 props로 주입합니다. 샘플 데이터는 `src/dev`에서만 사용합니다.
- 일주일 이내: 오늘 포함 7일, 종료 경계 제외. 한달 이내: 다음 달 같은 날짜 전까지, 해당 날짜가 없으면 다음 달 말일을 종료 경계로 사용합니다.
- 시간대는 시작 시각 기준으로 오전 [06,12), 오후 [12,18), 야간 [18,24) 또는 [00,06)입니다. 다음 날 종료 여부는 필터에 영향을 주지 않습니다.
- 최신순은 `publishedAt` 내림차순입니다. 입력 검색어의 모든 단어가 제목·매장명·업종·업무 중에 포함되어야 합니다. `es-hangul` 2.4.0의 `getChoseong`·`disassemble`로 초성(`ㅋㅍㅈ`)과 한글 입력 중(`컴ㅍ`) 검색을 지원합니다. 띄어쓰기·영문 대소문자·NFC/NFD를 정규화하고, 서로 다른 필드 사이를 연결해 매칭하지 않습니다.
- 필터 변경은 오버레이 안에서만 유지하고, 적용할 때 반영합니다. 닫기·Escape는 폐기하고 초기화는 선택만 초기화합니다.
- 검수: `/__jobs`, `/__jobs?empty=1`, `/__jobs?filter=1`. 샘플의 오늘은 2026-09-26입니다.
