# dev API 화면 연결

기준: dev OpenAPI **0.10.1**, backend `e5dfb48999468fab1d811ff60ae4a6e7bd1d644c`.
실제 주소는 같은 origin의 `/api`이며 dev/운영 간 쿠키나 절대 URL을 공유하지 않는다.

## 진입과 연결 범위

`/home?view=...&store=...&id=...`는 인증 경계에서 세션을 재검증한다. 뒤로가기·새로고침도 같은 서버 리소스를 조회한다. 점주 매장 권한은 홈 응답으로 버튼 진입을 검사하고 각 API에서 다시 검증한다.

| 화면 | 실제 요청 |
|---|---|
| 점주/근무자 홈 | 역할별 홈 집계, 한국 시간 월별 근무 일정 |
| 프로필 | 조회, 기본 정보 PATCH, 경력/가능 시간의 구역별 PUT |
| 공고 | 탐색/상세, 등록, 점주 목록/지원자, 지원/철회, 근무 요청, 모집 마감 |
| 매장 | 매장 선택/추가, 운영 집계, 근무자 목록/상세/접근 종료 |
| 초대 | 목록/생성/취소/재발송, 받은 초대 확인/수락/거절 |
| 메일 초대 | `/invitations/accept#token=...` 문맥 보관 후 로그인·가입 복귀, preview/accept/decline |
| 알림 | 목록, 읽음 처리, 타입별 내부 화면 이동 |
| 근무 요청 | 받은 요청 상세와 수락/거절, 서버 revision 사용 |
| 점주 매뉴얼 | 기존 음성 인터뷰/정정/사진/초안 검토/게시 서비스에 실제 CSRF·세션 연결 |
| 근무자 매뉴얼 | 접근 가능 매장, 게시 목록/업무 상세/사진 조회 |

목록은 서버 페이지를 순차 조회하며 빈 목록·0건은 그대로 표시한다. 100페이지를 넘기면 무한 요청 대신 오류로 중단한다. 현재 UI의 검색 필터는 가져온 공고에 적용한다. 대규모 목록의 서버 검색/점진 로딩은 별도 최적화다.

## 실패·동시성

- GET 및 변경 응답을 배포 계약으로 검사한다. 잘못된 응답은 가짜 성공이나 샘플 데이터로 바꾸지 않는다.
- 401은 로그인 화면으로 이동, 403/404 등은 현재 화면에서 실패·재시도를 제공한다.
- 변경 직전 CSRF를 조회하고 멱등성 키를 전송한다. 응답 유실 재시도에는 같은 의도의 키를 유지한다.
- 지원 철회/공고 마감/근무 요청·응답은 화면에서 읽은 revision을 전송한다. 충돌 시 실패로 남겨 뒤로가기·새로고침으로 최신 상태를 다시 읽도록 한다.
- 화면 이탈 시 요청 취소, 중복 제출 방지, 요청 대상 변경 시 이전 응답 노출 방지를 적용한다.
- 메일 토큰은 fragment에서 즉시 지우고 sessionStorage에서 최대 1시간 보관한다. 완료·취소 시 삭제하며 URL query/로그/분석에 넣지 않는다. 저장소를 차단한 브라우저는 로그인 후 메일 링크를 다시 열어야 한다.

## 남은 범위와 검증 한계

- `api/types.generated.ts`의 모든 operation이 화면에 노출되는 것은 아니다. 관리자 API, 근무자 AI 질문, 체크리스트 완료 저장, 관심 매장 편집, 점주의 확정 근무 취소는 이번 기존 화면 연결의 완료 범위가 아니다.
- 근무자 게시 목록/상세는 기존 공통 UI를 이용한 기본 조회다. #131의 Figma 전체 디자인 정합화나 AI 질문 화면 완성을 뜻하지 않는다.
- #161의 매뉴얼 디자인 변경을 통합했다. #159의 새 optional 안내 필드는 배포된 0.10.1에서 아직 송출되지 않는다. 기존 응답 허용을 검증했으며, 동적 안내 카드 제공과 사진 선택/생략만으로 인터뷰를 진행하는 명령은 서버 후속 작업이다.
- 캘린더 API는 읽기 전용이므로 실제 화면의 임의 일정 등록 버튼은 숨긴다.
- 자동 UI 테스트와 OpenAPI 예시 호환성 검사는 인증된 dev 사용자의 실제 저장·메일 발송·마이크·STT/AI 검증을 대신하지 않는다.

## 재생성·검사

```sh
node front-end/scripts/generate-api-contract.mjs /path/to/deployed-openapi.json
npm --prefix front-end run lint
npm --prefix front-end run test:ci
npm --prefix front-end run build
```

일반 업무 API는 배포 스냅샷으로 생성한다. 매뉴얼 작성 전용 계약은 `src/manual/`에서 관리한다. 서버 스키마·환경 설정 변경은 없다.
