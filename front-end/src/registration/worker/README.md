# 일반회원 프로필 등록

Refs #30. PR #37 위에 쌓는 UI 구현입니다. 일반회원 등록 Figma 255:687~255:694 및 업종 오버레이 436:2137을 기준으로 구현합니다.

## 미리보기

`npm run dev --prefix front-end -- --host 127.0.0.1 --port 5184 --strictPort`

- `/__auth/worker`: 빈 기본 정보 → 신입/경력 → 가능 시간 → 확인 → 완료
- `?step=work`: 신입 화면 비교용 샘플
- `?step=career`: 경력 요약 샘플. 경력 수정/추가로 편집 화면 이동
- `?step=time`: 시간표 샘플. 시간 수정/추가로 편집 화면 이동
- `?step=review`, `?step=complete`: 확인 및 완료 비교용 샘플

미리보기는 DEV 빌드에만 포함되고 쿠키를 만들거나 실제 가입 요청을 보내지 않습니다. 정상 최초 진입에는 이메일 대역 외의 입력값을 채우지 않습니다. 샘플 입력은 단계 이동/수정 동안 메모리에서 유지합니다. 제품 입력은 인증된 Google 이메일 범위의 sessionStorage에 30분 동안 보존하며 재인증 후 복원할 수 있습니다. 작성 중 페이지 이탈에는 브라우저 경고를 사용합니다.

## 입력 및 동작

- 외국인 성명 포함 1~50자. 법적 성명 길이 제한으로 해석하지 않습니다. 전화번호는 숫자/길이 제한과 자동 하이픈을 적용합니다.
- 생년월일은 숫자 8자리로 서식을 적용하며 윤년, 존재하지 않는 날짜, 미래 날짜를 검증합니다. 성별과 신입/경력 선택은 현재 Figma의 필수 항목입니다.
- 경력은 업종·업무·선택 매장명·시작/종료 연월·재직 여부를 보유합니다. 명세에 따라 0000년·미래 연월·역전 기간을 거부합니다. 여러 직장의 경력 기간은 겹칠 수 있습니다. 신입으로 바꾸면 편집 중 경력을 유지하되 제출에서는 제외합니다.
- 시간은 30분 단위로 등록하고 0시간/24시간 초과, 중복 요일, 같은 주의 겹침을 거부합니다. 다음 날 종료와 일요일→월요일 경계를 포함합니다. 인접 구간은 허용합니다.
- 시간표는 06:00~24:00의 30분 셀을 선택/해제합니다. 드래그는 같은 요일 안의 연속 구간을 편집합니다. 키보드 클릭과 별도 시간 추가 폼으로도 편집할 수 있습니다. 그리드 편집 시 00:00~06:00 데이터도 보존합니다.
- 확인 화면에서 수정 후 확인 화면으로 복귀합니다. 제출 중 수정/중복 클릭을 막습니다. 내용 변경 시 새 요청 키를, 실패 후 동일 내용 재시도에는 같은 키를 씁니다. 15초 시간 제한 이후 늦은 성공 응답은 무시합니다.
- 업종 오버레이는 기존 IndustryPicker를 재사용합니다. 연월/시간은 Figma 448:2429, 448:2476, 448:2523, 448:2599의 휠 오버레이를 공통 PickerDialog 안에 구현합니다. 연도·월·시는 스크롤/키보드로, 분은 00·30분 버튼으로 선택합니다. 다음 날 종료는 종료 시간 오버레이에서 확인할 때 함께 저장합니다.

## 서버 연동 경계

기본 WorkerService는 `GET /api/auth/registration`으로 확인한 이메일을 읽고 `POST /api/auth/registrations/workers`에 최종 입력을 제출합니다. 공통 API 클라이언트의 쿠키·CSRF·멱등성 key와 10초 제한을 적용합니다. UI 역할/경력/요일/시간을 명세의 코드와 문자열로 변환하고 UI id·읽기 전용 이메일은 전송하지 않습니다. 신입의 careers는 빈 배열, 재직 경력의 endMonth는 null, 빈 선택 매장명은 생략합니다. 경력은 최대 20건, 가능 시간은 최대 100건, 담당 업무는 300자, 휴대전화는 010 11자리입니다. 날짜의 기준은 Asia/Seoul입니다.

서버 Session의 WORKER/WORKER_HOME을 확인한 뒤 완료 화면을 표시하고 `/home`에서 회원 세션을 재조회합니다. 가입 오류 code별 안내와 422 필드 매핑, 만료 후 입력 보존 및 재인증 전 제출 차단을 제공합니다. 실제 Google SSO·가입·쿠키 전환의 E2E는 사용자가 수행합니다. 미연동 프로필 편집 서비스 및 개발 미리보기의 샘플 서비스는 유지합니다. DB/config 변경은 없습니다.

## 검증

- 전체 27개 테스트 파일, 136개 테스트 통과. 빈 폼부터 완료, 경력 추가/수정, 겹친 시간, 윤년, 주 경계, 그리드 편집/취소, 실패 재시도, 중복 제출과 늦은 성공 무시를 검증합니다.
- `npm run test:ci --prefix front-end`, `npm run lint --prefix front-end`, `npm run build --prefix front-end`, `git diff --check` 통과.
- 기존 Safari에서 빈 기본 정보, 경력 요약/편집, 시간표 셀 선택 시 총 시간 갱신, 확인 및 개발 대역 완료 화면을 확인했습니다. 320px 경력 폼과 1440px 중앙 프레임(x525, 너비390)을 확인했습니다.
- 완료 화면은 상태 원 x24/y106/48×48, 제목 y174/33px, 카드 y258/342px로 원본 배치를 확인했습니다. 2026-09-25 Figma 아이콘 갱신에 따라 등록·완료 화면의 뒤로가기 SVG(8.7×15.7), 경력·시간 선택 SVG(7.533×13.3667), 완료 화면의 정보 SVG(21.7×21.7)를 적용했습니다. 각 SVG의 선은 기존 디자인 슬롯 안에 정렬합니다.
- 실제 포인터 드래그는 브라우저 자동화 도구가 noWindowsAvailable 오류를 반환하여 자동화 테스트로 검증했습니다. 실제 모바일 터치 드래그, 휠 선택기의 실제 모바일 터치, 실제 API는 미검증입니다.
- Safari 콘솔에 출처 URL 없는 리소스 접근 권한 오류가 관찰됐습니다. 앱 화면은 정상 렌더됐으나 해당 리소스 오류 원인은 미확인입니다.
- production JS에서 개발 미리보기 경로/이메일/접수 식별자가 제거됨을 확인했습니다. stacked base는 현재 CI 트리거 대상이 아니므로 로컬 검증을 기록합니다.

- 2026-09-25 디자인 갱신: 경력/시간 요약의 수정 버튼 우측 정렬, 시간 편집 안내 단순화, 연월/시간 오버레이 적용. Safari 390px에서 오버레이와 스크롤·키보드 선택·분 전환·취소를 확인했습니다.

- 휠 스크롤 중 React 값 갱신이 scrollTop을 재지정하지 않도록 수정했습니다. 중간 오프셋 유지와 키보드 이동을 회귀 테스트로 검증합니다.
