# 지단 — 연결형 프론트엔드 프로토타입

Figma **Design** 페이지의 모바일 디자인을 React 19 + TypeScript + Vite로 구현했습니다. 390px 화면을 기준으로 작은 모바일 화면에도 대응합니다. Pretendard GOV, 색상·간격·카드·버튼 규칙을 적용했고 Figma SVG와 폰트는 로컬 자산으로 제공합니다.

디자인: https://www.figma.com/design/ZaFHresnBXJ1h98Xl1AUDj?node-id=0-1

## 실행

Node.js 22.12 이상을 사용하세요.

```bash
cd front-end
npm ci
npm run dev
```

기본 주소는 http://localhost:5173 입니다. 로그인 화면의 **SSO 계정으로 시작하기**에서 가입 유형을 선택합니다. 점주 체험은 샘플 매장으로 시작합니다. 새 매장은 홈의 **매장 추가**에서 등록합니다.

데스크톱 왼쪽 도구로 점주·근무자를 바로 전환할 수 있습니다. 모바일에서는 **프로필 → 프로토타입 계정 전환**을 사용합니다. 가입·초대·공고·매뉴얼 변경 사항은 두 역할에서 같은 데이터를 사용하며 새로고침 후에도 유지됩니다. 데이터 키는 `jidan-prototype-v1`입니다.

## 연결된 흐름

- **일반회원 가입**: 기본 정보 → 신입/경력 및 경력 추가 → 30분 단위 주간 가능 시간 → 내용 확인 및 수정 → 완료. 심야 시간은 다음 날로 분리하고 겹치는 시간은 병합합니다.
- **점주 운영**: 홈 → 매장 관리 → 근무자 초대/목록/상세. 이메일이 일치하는 계정만 7일 이내 초대를 수락할 수 있습니다. 수락하면 담당 업무의 매뉴얼 접근이 추가되고, 접근 종료는 해당 근무 관계만 종료합니다.
- **매뉴얼**: 설명 입력 → 보완 질문 → 초안 편집 → 검토 → 승인·게시 → 근무자 열람/체크/질문. 단계별 사진 선택·미리보기·로컬 저장을 지원하며 수정 초안 작성 중에도 기존 게시본과 사진은 유지합니다. 담당 업무와 유효한 근무 관계에 따라 직접 URL 접근도 제한합니다.
- **대타**: 점주 공고 등록 → 근무자 검색·날짜/경험/가능 시간 필터 → 신청/철회/관심 저장 → 점주 지원자 확정 → 즉시 담당 업무 온보딩. 시작 시각, 중복 신청, 모집 정원, 확정 일정 충돌을 검사합니다. 임시 접근은 근무 종료 때 만료됩니다.
- **기타**: 홈 캘린더 월/일 선택, 활동 요약, 알림 진입, 프로필 수정, 브라우저 뒤로가기, 확인 모달과 오류/빈 상태를 연결했습니다.

## 데모 범위

- 현재 백엔드는 `GET /api/health`만 제공합니다. 업무 기능은 브라우저의 샘플 데이터로 동작하며 실제 계정이나 서버 데이터를 변경하지 않습니다. `/api` 프록시는 기존대로 `127.0.0.1:8000`을 유지합니다.
- SSO는 샘플 계정 진입입니다. 이메일은 전송하지 않으며 초대 링크는 같은 브라우저의 저장 데이터에서 체험합니다.
- AI 초안은 입력한 문장의 단계 분리, 음성 입력은 사전 전사 예시, 질문은 게시된 매뉴얼의 키워드 검색입니다. 실제 AI·음성 인식 API는 호출하지 않습니다. 근거가 없거나 모호하면 담당자 확인 또는 추가 설명을 안내합니다.
- 매장 주소 검색은 월계1동 샘플 주소를 사용합니다. 신규 매장은 관리 자격 확인 대기 상태이며 실제 사업자 인증은 없습니다. 현재 프로토타입은 한 매장을 관리하므로 신규 등록 시 기존 매장 데이터 교체를 확인받습니다.
- 체크리스트와 질문 대화는 현재 화면에서만 유지합니다. 숙련도·진도 저장은 없습니다. 영상 업로드와 실제 파일 서버는 구현 범위에 포함하지 않습니다.

## 검증

```bash
npm run lint
npm run test:ci
npm run build
```

테스트는 가입·검증·심야 시간 병합, 초대 계정/만료/중복, 권한 종료, 게시본 보호, 공고 신청/철회/확정/충돌/시작 시각 재검증, 역할별 라우트 접근을 확인합니다.

`src/model.ts`와 `src/AppProvider.tsx`는 공유 데이터와 로컬 저장, `src/job-logic.ts`는 일정·확정 규칙, `src/pages/`는 가입·매장·매뉴얼·공고 화면, `src/ui.tsx`와 CSS는 공통 디자인을 담당합니다.
