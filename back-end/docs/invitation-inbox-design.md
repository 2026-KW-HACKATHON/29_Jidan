# 일반회원 초대 알림 연결

Figma 일반회원 알림의 매장 초대에서 token이 없는 앱 내부 수락 화면으로 이동해야 하므로 초대함 API를 보완합니다. 세션의 검증된 Google 이메일과 초대 대상 일치가 필수이며 회원 ID만으로 다른 초대를 조회할 수 없습니다. 기존 이메일 token 경로와 같은 초대 레코드/잠금/수락 로직을 사용하고 토큰을 알림에 담지 않습니다. 수락 시 같은 매장에 유효한 REGULAR 접근이 이미 있으면 기존 접근을 200으로 반환하고 새 접근을 만들지 않으며 초대는 PENDING으로 둔다. 기존 접근은 다른 초대에서 생긴 것이므로 이 초대를 ACCEPTED로 기록하지 않는다(재수락 판정이 초대 ID로 접근을 찾기 때문). 이메일 링크 API는 같은 경우 409 WORKER_ALREADY_HAS_ACCESS를 유지한다. 대타 TEMPORARY 접근은 정기 초대 수락을 막지 않는다.
