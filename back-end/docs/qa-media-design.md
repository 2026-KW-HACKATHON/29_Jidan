# AI 업무 질문 미디어

카메라·마이크 입력은 점주 인터뷰 업로드와 주체가 달라 별도 QA 미디어 API를 사용합니다. 현재 USE_AI_QA 접근이 있는 본인만 업로드/조회/전사할 수 있고 파일은 같은 매장·본인 대화에만 연결합니다. 사진은 맥락 입력일 뿐 점주 매뉴얼을 대체하는 사실 근거가 아닙니다.

사진 10MiB/7일, 음성 20MiB·2분/24시간은 설계 제안입니다. 전사 READY 후 텍스트를 수정해 질문하거나 transcriptionId를 보낼 수 있습니다. 전사 재시도는 ERROR·유효 음성에 한정하며 접근 종료 후 늦게 끝난 작업 결과도 열람을 허용하지 않습니다.
