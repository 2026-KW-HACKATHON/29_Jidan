# 홈 요약·추천 계약

Figma 홈 요약은 역할별 집계 API로 제공하며 알림·활동 건수는 동일 asOf로 계산합니다. 월별 전체 캘린더는 분리합니다. 점주는 전체 소유 승인 매장을 조회하고 storeId로 선택 매장을 제한할 수 있습니다.

사용자 확정 추천: **시간이 맞는 공고 먼저 → 그 안에서 근무일 가까운 순**입니다. 시간 일치는 주간 가능 시간의 합집합이 실제 근무 구간 전체를 덮는 것으로 정의합니다. 일치 여부 DESC, startAt ASC, id ASC이며 최신 등록순을 사용하지 않습니다. 일부만 겹치거나 가능 시간 등록이 없으면 불일치로 뒤에 표시하고, 같은 일치 여부에서는 근무 날짜/시각 순입니다. matchesAvailability로 판단 결과를 응답합니다.

서울 기준 전날 심야 및 SUN→MON 구간을 포함합니다. 인접 시간들을 합쳐 덮을 수 있고 경계에 닿기만 하면 불일치입니다. 승인된 월계1동 매장·모집 중·미래 시작·미확정·현재 유효 본인 지원이 없는 공고 중 최대 3개를 추천합니다. 철회 이력만 있으면 재지원이 가능하므로 후보에 들어옵니다. 최소 경력 안내 정책은 유지합니다.

예시에 시간 일치가 더 가까운 불일치를 앞서는 경우, 같은 일치 여부의 날짜 순서, 인접 가능 시간 합집합, 일요일 심야의 월요일 적용, 경계 불일치, 등록 시간이 없는 경우를 포함했습니다. 날짜 간 관계·실제 정렬은 향후 구현 테스트로 검증해야 합니다.

정기 근무 매장 수는 현재 정기 자료 접근이 있는 매장 건수입니다. 정기 캘린더 MVP 제외와 별개입니다. 첫 선택 매장·집계 상한은 기존 설계 제안을 유지합니다.
