# 지원·철회·재지원 계약

자기소개 최대 500자, 제출 당시 이름·나이·경력 스냅샷을 지원 시도마다 보관합니다. 이후 프로필 수정이 기존 지원서를 바꾸지 않습니다. 생일·연락처·이메일은 점주 지원서에 노출하지 않습니다.

사용자 확정: 철회한 근무자는 공고 페이지에서 다시 지원할 수 있습니다. 새 key로 새 applicationId를 생성하고 과거 WITHDRAWN 지원서/취소 요청 이력은 유지합니다. 현재 유효 지원은 같은 공고·회원에 하나뿐이며 마감·시작·확정된 공고에는 재지원할 수 없습니다.

목록은 지원 시도별 항목입니다. 이전 철회는 종료 탭, 새 지원은 신청 중 탭에 표시합니다. 과거 key 재시도는 원래 결과 재현이고 재지원으로 처리하지 않습니다. 경력 조건 안내 정책은 유지합니다. 점주 요청 철회/확정 철회는 근무 요청 챕터에서 별도로 정의합니다.
