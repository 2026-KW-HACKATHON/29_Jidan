# 점주 AI 인터뷰 실행 흐름 (검수 초안)

이 문서는 점주의 암묵지를 업무 매뉴얼 초안으로 수집하는 **인터뷰 실행 순서**를 정의한다. [업무 매뉴얼 ERD](manual.md)는 저장 구조를 설명하며, 이 문서는 질문·답변·추가 탐문의 분기를 설명한다. 아직 API 또는 AI 실행 로직의 구현 완료를 뜻하지 않는다.

## 인터뷰 진행 순서

1. 세션을 시작할 때 필수 질문 셋의 버전을 고정한다. 질문 셋은 순서가 있는 **필수 인텐트**의 목록이다. 각 인텐트에는 기본 질문과 수집하려는 정보의 기준이 있다.
2. 현재 인텐트의 기본 질문을 점주에게 한 개 제시한다. 이전 답변에 따라 문구를 조정할 수 있지만, 필수 인텐트 자체를 건너뛰지는 않는다.
3. 점주의 음성 또는 텍스트 답변을 전사 텍스트로 기록한다.
4. **그 답변과 현재 인텐트의 문맥을 Jev에 전달해 추가 질문이 필요한지 판단한다.** 점주가 결과만 말하거나 조건·작업 순서·판단 기준·예외를 빠뜨린 경우가 추가 탐문의 대상이다.
5. Jev가 추가 질문이 필요하다고 판단하면 별도 생성 단계에서 현재 인텐트에 속하는 추가 질문 한 개를 만들어 점주에게 묻는다. 그 답변을 기록한 직후 현재 인텐트의 기본 질문부터 누적한 질문·답변으로 4번의 판단을 다시 수행한다. 추가 질문은 depth 1~5에서 한 개씩 생성하며, 상한에서도 부족하면 해당 인텐트를 검수중으로 표시하고 점주 확인을 기다리지 않은 채 바로 다음 인텐트로 이동한다. 추가 질문이 필요 없으면 현재 인텐트를 완료하고 다음 필수 인텐트로 이동한다.
6. 마지막 필수 인텐트까지 진행한 후 수집된 답변으로 매뉴얼 초안을 만들고, 점주가 수정·확인한 뒤 게시한다. AI가 초안을 자동 게시하지 않는다.

```text
필수 인텐트 i의 기본 질문 (depth 0)
  → 점주 답변 저장
  → Jev에 답변과 인텐트 문맥 전달·추가 질문 필요 여부 판단
      ├─ 필요·depth < 5: 다음 depth의 추가 질문 한 개 생성 → 답변 하나 저장 → Jev 재판단
      ├─ 필요·depth = 5: 인텐트를 검수중(NEEDS_DETAIL)으로 표시 → 확인 대기 없이 다음 인텐트
      └─ 불필요: 인텐트 i 완료 → 다음 필수 인텐트(i+1)
모든 필수 인텐트 진행 → 매뉴얼 초안 → 점주 검토·게시
```

질문 셋의 모든 인텐트를 진행한다. 기본 질문은 각 인텐트마다 한 번 진행하며, 문구는 이전 답변에 맞게 조정할 수 있다. 추가 질문도 한 번에 한 개만 제시한다. 정보가 충분해지는 즉시 다음 필수 인텐트로 이동한다. 이전 답변에 다음 인텐트의 내용이 일부 포함되었다면 해당 인텐트에서 확인 질문을 한다.

## depth와 실패 시 진행

기본 질문은 depth 0이고 새로운 추가 질문 한 개를 생성할 때 depth를 1씩 증가시킨다. API의 batchId와 ERD의 probe batch는 질문 한 개의 생성 단위를 식별한다. 재시도는 같은 단위와 depth를 유지하며 depth 6 질문을 생성하지 않는다.

depth 5에서도 추가 정보가 필요하면 해당 인텐트를 `NEEDS_DETAIL`로 남기고 화면에 **검수중**으로 표시한다. `finished_at`을 기록하고 **점주 확인을 기다리지 않은 채 즉시 다음 인텐트로 이동**한다. 마지막 인텐트면 바로 초안 생성 준비 단계로 이동한다. 검수중은 해당 항목의 표시이며 세션을 이해 확인 대기 상태로 멈춘다는 뜻이 아니다.

이 항목은 최종 매뉴얼 초안에서 다시 표시한다. 사용자가 결정한 정책에 따라 최종 검토에서 점주 확인만으로 게시할 수 있으며 추가 보완 답변은 필수가 아니다. 점주 확인은 원래 `NEEDS_DETAIL` 판단을 `COVERED`로 바꾸지 않는다.

질문 생성 또는 Jev 평가가 실패하면 자동 재시도 후 fallback을 수행한다. fallback까지 실패하면 점주에게 오류를 표시하고 진행을 멈춘다. 기존 질문·답변과 현재 묶음을 보존하고, 재개 시 실패한 작업부터 수행한다. 실패 중에는 다음 인텐트로 이동하거나 depth를 증가시키지 않는다. 답변이 이미 저장된 평가 실패는 해당 답변으로 평가를 다시 수행한다.

생성한 질문 한 개를 저장하고 READY로 전환한 뒤 제시한다. 답변 하나를 저장할 때마다 평가하며 다른 질문의 답변을 기다리지 않는다. 평가 입력과 판단 설정을 보존하고 성공 결과는 한 번만 진행 상태에 적용한다. 저장과 상태 전환의 제약은 [업무 매뉴얼 ERD](manual.md)를 따른다.

## 예시

| 순서 | 대화 | 판단 |
| --- | --- | --- |
| 기본 질문 | AI: “마감할 때 어떤 일을 하나요?” | `마감 업무` 인텐트 시작 |
| 답변 | 점주: “기계 닦고 쓰레기 정리해요.” | 작업 순서와 완료 기준이 드러나지 않음 |
| 추가 질문 depth 1 | AI: “기계는 어떤 순서로 닦나요?” | 같은 인텐트의 부족 정보 질문 한 개 |
| 추가 답변 | 점주가 기계 청소 순서를 답함 | 즉시 Jev가 누적 문맥으로 평가 |
| 추가 질문 depth 2 | 여전히 부족하면 AI: “쓰레기는 어디에 버리나요?” | 충분했다면 이 질문 없이 다음 인텐트로 이동 |
| 다음 질문 | 추가 질문이 필요 없으면 다음 필수 인텐트로 이동 | `마감 업무` 인텐트 완료 |

점주 답변을 저장한 뒤 Jev 판단을 수행한다. 판단이 끝나면 추가 질문 또는 다음 필수 질문으로 진행한다. Jev는 정해진 형식의 판단값을 반환한다. 추가 질문 문구는 별도 단계에서 만든다. [TypeSafe 공식 설명](https://docs.typesafe.ai/introduction)
