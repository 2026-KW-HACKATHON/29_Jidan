# 대타 공고 계약

Figma 등록 3단계는 최종 POST 1회로 제출합니다. 근무 파트·경력·지급 시점의 코드가 각 선택지를 그대로 표현합니다. 단일 근무자 모집이며 공고 생성에 개인정보·승인 상태·매장 업종을 입력받지 않습니다.

사용자 확정: 근무 요청 수락과 동시에 공고를 RECRUITING→CLOSED로 마감하고 closedAt을 수락 시각으로 기록합니다. 근무 시작 전 확정 철회는 CLOSED→RECRUITING으로 다시 열고 closedAt=null로 초기화합니다. 원래 마감과 확정·철회 이력은 보존합니다. 재개된 공고는 신규 지원과 새 근무 요청을 받을 수 있습니다.

선정 없이 모집을 끝내거나 확정 철회로 다시 열린 공고를 마감할 때 closure를 사용합니다. 유효 대기 요청은 먼저 철회해야 합니다. 이미 CLOSED이면 근무 시작 전·진행 중·완료 후 모두 최신 revision으로 200 현재 상태를 반환하며 최초 closedAt·revision·확정·접근·일정 이력을 바꾸지 않습니다. 새 key의 오래된 revision은 409, 같은 key 재시도는 최초 결과입니다.

수락·확정 철회·수동 마감은 공고 잠금으로 직렬화합니다. 수락이 먼저면 이전 revision의 마감은 실패하고, 마감이 먼저면 수락은 실패합니다. 근무 종료만으로 다시 열리지 않습니다. 시간대는 Asia/Seoul이고 심야 근무·계산 보수·미래 시작 검증은 API description에 정의한 설계 정책입니다.
