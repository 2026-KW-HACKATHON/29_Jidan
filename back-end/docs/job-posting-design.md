# 대타 공고 계약

Figma 등록 3단계는 최종 POST 1회로 제출합니다. 근무 파트·경력·지급 시점의 코드가 각 선택지를 그대로 표현합니다. 단일 근무자 모집이며 공고 생성에 개인정보·승인 상태·매장 업종을 입력받지 않습니다.

사용자 수정 디자인에 따라 시작 전 확정은 확정 철회 후 별도 모집 마감합니다. 유효 대기 요청도 요청 철회를 먼저 수행합니다. 진행 중 확정은 마감할 수 없고 완료 후에는 이력을 보존한 채 마감합니다. 미선정 지원 종료를 공고 잠금과 같은 트랜잭션으로 수행합니다. 시간대는 Asia/Seoul이고 심야 근무·계산 보수·미래 시작 검증은 API description에 정의한 설계 정책입니다.
