# MVP 전체 캘린더 계약

사용자 결정으로 정기 근무 캘린더는 MVP에서 제외합니다. 월별 전체 조회 API 두 개만 제공합니다.

- GET `/api/users/me/calendar/events?month=YYYY-MM`: 본인의 모든 매장 확정 대타와 완료 이력.
- GET `/api/owners/me/calendar/events?month=YYYY-MM`: 소유 승인 매장의 확정 대타와 완료 이력. 선택적인 `storeId`로 홈 선택 매장을 제한할 수 있습니다.

이벤트는 TEMPORARY_WORK만 반환합니다. 정기 접근과 가입 가능 시간은 근무 일정이 아닙니다. 일반 일정/정기 일정 등록·수정·삭제 및 단일 일정 상세 API는 제외합니다. 근무자 조회는 본인, 점주 조회는 현재 소유 승인 매장만 포함합니다.

수락으로 생성한 대타 일정은 근무 확정 철회 시 활성 캘린더에서 제외하며 감사 이력은 삭제하지 않습니다. 근무 완료 후 과거 이력은 남지만 자료 접근을 부여하지 않습니다. 정기 접근이 남아 있어도 철회된 대타는 다시 표시하지 않습니다.

서울 월 범위와 반열린 구간이 겹치는 월말 심야를 원래 시각 그대로 반환합니다. 경계에 닿기만 하면 제외하고 startAt ASC/id ASC로 정렬합니다. 빈 월은 events=[], 1000개 초과는 422이며 결과를 자르지 않습니다. 알림의 workDate로 월을 열고 eventId를 강조합니다.
